# Materiais de Estudo - Rocketseat React

Este repositório reúne meus estudos, exercícios e projetos desenvolvidos durante a formação em **React** da **Rocketseat**. Aqui documento minha evolução na construção de **interfaces modernas, reutilizáveis e escaláveis** utilizando o ecossistema React.

O objetivo deste repositório é consolidar conceitos fundamentais do **desenvolvimento Frontend com React**, explorando desde fundamentos da biblioteca até práticas utilizadas no mercado, como **componentização, gerenciamento de estado e integração com APIs**.

## 📚 **Sobre o Curso**

A formação em **React da Rocketseat** é focada no desenvolvimento de **interfaces web modernas e performáticas** utilizando o ecossistema React.

Durante o curso, são explorados conceitos essenciais como:

- Estruturação de aplicações com **componentes reutilizáveis**
- Uso de **Hooks** para gerenciamento de estado e efeitos
- Consumo de **APIs**
- Boas práticas de organização de código
- Integração com ferramentas modernas do ecossistema frontend

Ao longo da formação, desenvolvo projetos práticos que simulam **cenários reais de desenvolvimento de interfaces web**.
